# Окна контекста веб-провайдеров

Каталог ротатора и локальные настройки OMP должны объявлять одинаковые окна.
Это общий бюджет контекста, а не гарантия принятия любого запроса такой длины:
инструменты, изображения, системные сообщения и ответ тоже требуют места.
Название модели в каталоге не подтверждает доступность модели на аккаунте.

| Маршрут | Рабочее окно, токены | Основание |
| --- | ---: | --- |
| Argon Low / Medium / High | 1 000 000 | Gemini App на AI Pro: официальное окно плана |
| ChatGPT App: gpt-6 / gpt-5-6-mini | 32 768 | Консервативный предел адаптера для подключённых бесплатных аккаунтов |
| Claude App: Sonnet 5.5 | 200 000 | Рабочий предел для бесплатных аккаунтов, не обещание окна платного плана |
| Qwen 3.5 Omni Plus | 262 144 | Опубликованное окно этой модели |
| Qwen 3.5/3.6/3.7 Plus, 3.7/3.8 Max, 3.8 Omni Flash | 1 000 000 | Опубликованные окна моделей; доступное окно веб-плана отдельно не измерялось |
| DeepSeek App: current | 1 000 000 | Текущий маршрут V4.1 Flash 1017; семейство V4 доступно в веб-чате с окном 1M |

У неизвестных моделей и `claude-app-auto` окно остаётся неизвестным (`null`).
При смене модели за алиасом `deepseek-app-current` нужно пересмотреть его окно.
`modelSpecs["<полный ID маршрута>"].contextWindow` в конфигурации ротатора позволяет
задать операторский предел веб-маршрута; локальную настройку клиента следует
обновлять вместе с ним. Встроенное окно Argon задано отдельно в `credentials.ts`.

Для ChatGPT нельзя переносить размер API-контекста на бесплатный веб-аккаунт.
Для Claude официальное окно Sonnet 5.5 в 1M описано для платных планов; это не
основание обещать его бесплатной сессии. Оба рабочих предела можно пересмотреть
после подтверждения возможностей конкретного веб-плана.

Argon дополнительно ограничен 16 МиБ UTF-8 сформированного промпта в TypeScript
и Python. Это независимый предел байтов, а не перевод токенов в символы.
Предел ответа в 128 000 символов и настройки генерации этим изменением не повышены.
Нагрузочная проверка полного окна не проводилась.

В OMP автосжатие остаётся на 200 000 токенов: большое окно модели не требует
заполнять его целиком. Клиент также должен учитывать меньшее окно выбранной
модели. Лимиты нативных провайдеров и их параметры генерации не меняются.
